Virtual Head 使い方

画像・動画・カメラの実写頭部へ、Minecraft互換SkinのVoxel頭部を重ねるWindowsアプリです。

最初に入力とモデルを選び、必要なら保存を有効にして「開始」を押します。設定は開始時に自動保存され、次回起動時に復元されます。

1入力を選ぶ
2モデルを確認
3見た目を調整
4開始する

画面全体

  1. 1左側のタブで入力、モデル、見た目を設定します。
  2. 2右側に処理中の映像を表示します。
  3. 3設定後に「開始」を押します。
  4. 4使い方、ライセンス、設定保存、保存先を開けます。

動画を処理する

  1. 1入力で「動画」を選びます。
  2. 2処理する動画を選択します。
  3. 3使用するSkin PNGを選択します。空欄ならサンプル頭部です。
  4. 4ファイルへ残す場合は「結果を保存する」を有効にします。
  5. 5保存先フォルダを選択します。
  6. 6「開始」を押し、完了まで待ちます。

音声を残す場合はFFmpegを指定し、「入力動画の音声を残す」を有効にします。出力先にはoverlay.mp4、tracking.jsonl、run.jsonが作られます。

画像を処理する

  1. 1入力で「画像」を選びます。
  2. 2PNG、JPEG、BMP、WebP画像を選択します。
  3. 3Skin PNGを選択します。
  4. 4「結果を保存する」と保存先を確認します。
  5. 5「開始」を押します。1枚だけ処理して自動終了します。

出力先にはoverlay.png、tracking.jsonl、run.jsonが作られます。

カメラで使う

  1. 1入力で「カメラ」を選びます。
  2. 2通常はカメラ番号0を使います。
  3. 3Skin PNGを選択します。
  4. 4「開始」を押すとカメラが開きます。
  5. 5終了時は「停止」を押します。

録画する場合だけ「結果を保存する」を有効にします。カメラ録画に音声は入りません。

モデルを設定する

  1. 1対応する頭部検出ONNXを選択します。
  2. 2対応する回転角ONNXを選択します。
  3. 3まずCPUで動作確認し、必要に応じてCUDAへ切り替えます。
  4. 4CUDA DLLが自動検出されない場合だけフォルダを指定します。
  5. 5Roll補助が必要な場合だけランドマークを有効にします。
  6. 6音声付きH.264保存にはFFmpegを指定します。
モデルは配布物に含まれません。信頼できる入手元から取得した、Virtual Headの入出力仕様に合うONNXだけを指定してください。

頭の見た目を調整する

  1. 1頭の拡大率。初期値18%は検出した頭の基準サイズの1.18倍です。
  2. 2固定Pitch。頭の上面・下面の見え方を調整します。
  3. 3左右の位置ずれを補正します。
  4. 4上下の位置ずれを補正します。負の値で上へ移動します。
  5. 5追従の揺れを平滑化します。
  6. 6Skinの髪・帽子レイヤーを表示します。

開始・停止・保存

  1. 1処理を開始します。
  2. 2動画やカメラ処理を安全に終了します。
  3. 3この説明書を開きます。
  4. 4現在の設定を保存します。
  5. 5直近の保存先をエクスプローラーで開きます。

うまく動かないとき

開始できない

入力、頭部検出モデル、回転角モデルの選択を確認します。

GPUエラー

CPUへ切り替えて確認します。CUDA使用時は対応するCUDAとcuDNNが必要です。

頭がずれる

拡大率、左右・上下位置、固定Pitchを少しずつ調整します。

診断ログは%LOCALAPPDATA%\VirtualHead\app.log、実行結果は出力先のrun.jsonにあります。

映像、画像、モデル、SkinはPC内で処理され、Virtual Headから外部へ送信されません。これは非公式アプリであり、MojangまたはMicrosoftの承認・提携を受けていません。
