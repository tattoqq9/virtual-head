Virtual Head 使い方

画像・動画・カメラの実写頭部へ、Minecraft互換SkinのVoxel頭部を重ねるWindowsアプリです。

GitHubからWindows用ZIPを取得して展開し、初回だけ標準モデルをダウンロードします。その後、入力と見た目を設定して「開始」を押します。

1ZIPを取得
2モデルを取得
3入力を選ぶ
4見た目を調整
5開始する

GitHubからダウンロードする

Virtual HeadのReleaseページを開き、先頭に表示される新しい版を選びます。アプリ画面下の「最新版・Release」ボタンからも同じページを開けます。

  1. 1「Releases」を開き、新しいVirtual Headの版を選びます。
  1. 1最も新しいバージョンであることを確認します。
  2. 2Assetsが閉じている場合はクリックして開きます。
  3. 3VirtualHead-バージョン-windows-x64.zipをダウンロードします。これがWindowsアプリ本体です。
  4. 4.zip.sha256は改ざん確認用です。「Source code」はアプリ本体ではありません。

ダウンロードしたZIPを右クリックして「すべて展開」します。展開後のVirtualHead.exeと_internalフォルダは同じ場所に置いたまま使用してください。

初回のSmartScreen表示

現在のプレリリースはコード署名前のため、「WindowsによってPCが保護されました」と表示されます。公式Releaseから取得したZIPであることを確認し、可能ならRelease記載のSHA-256と照合してください。

  1. 1確認できたファイルだけ「詳細情報」を開きます。
  2. 2アプリ名がVirtualHead.exeであることを確認して「実行」を押します。

警告を解除する手順

  1. 1「許可する」にチェックします。
  2. 2「適用」→「OK」を押してからZIPを展開し直します。
  1. GitHubの公式ReleaseからVirtualHead-バージョン-windows-x64.zipと.zip.sha256を取得します。
  2. PowerShellでGet-FileHash .\VirtualHead-バージョン-windows-x64.zip -Algorithm SHA256を実行し、Release記載値と一致することを確認します。
  3. ZIPを右クリックして「プロパティ」を開きます。全般タブ下部に「許可する」または「ブロックの解除」がある場合はチェックし、「適用」→「OK」を押します。
  4. 解除したZIPを「すべて展開」し、VirtualHead.exeを起動します。
  5. SmartScreen画面が表示された場合は「詳細情報」→「実行」を選びます。

プロパティに解除項目がない場合は、SHA-256確認後にPowerShellでUnblock-File -LiteralPath .\VirtualHead-バージョン-windows-x64.zipを実行し、ZIPを展開し直せます。SmartScreen自体を無効にする必要はありません。

「実行」が表示されず、Windows 11のSmart App Controlがブロックしている場合、この未署名版をファイル単位で許可する方法はありません。PC全体の保護機能を無効にすることは推奨しません。
メール、広告、第三者サイトから入手した同名ファイルでは、この解除操作を行わないでください。必ずgithub.com/tattoqq9/virtual-headのReleaseから取得してください。

画面全体

  1. 1左側のタブで入力、モデル、見た目を設定します。
  2. 2右側に処理中の映像を表示します。
  3. 3設定後に「開始」を押します。
  4. 4使い方、最新版のRelease、ライセンス、設定保存、保存先を開けます。

動画を処理する

  1. 1入力で「動画」を選びます。
  2. 2処理する動画を選択します。
  3. 3使用するSkin PNGを選択します。空欄ならサンプル頭部です。
  4. 4ファイルへ残す場合は「結果を保存する」を有効にします。
  5. 5保存先フォルダを選択します。
  6. 6「開始」を押し、完了まで待ちます。

音声を残す場合はFFmpegを指定し、「入力動画の音声を残す」を有効にします。出力先にはoverlay.mp4、tracking.jsonl、run.jsonが作られます。

画像を処理する

  1. 1入力で「画像」を選びます。
  2. 2PNG、JPEG、BMP、WebP画像を選択します。
  3. 3Skin PNGを選択します。
  4. 4「結果を保存する」と保存先を確認します。
  5. 5「開始」を押します。1枚だけ処理して自動終了します。

出力先にはoverlay.png、tracking.jsonl、run.jsonが作られます。

カメラで使う

  1. 1入力で「カメラ」を選びます。
  2. 2通常はカメラ番号0を使います。
  3. 3Skin PNGを選択します。
  4. 4「開始」を押すとカメラが開きます。
  5. 5終了時は「停止」を押します。

録画する場合だけ「結果を保存する」を有効にします。カメラ録画に音声は入りません。

モデルを設定する

  1. 1頭部検出器を用途別の一覧から選びます。Goldは高速、YOLOv9-tは標準、DEIMv2はGPU向けです。
  2. 2実際に使用する頭部検出ONNXを表示します。未取得の場合は「選択」から指定します。
  3. 3回転角モデルを選びます。通常はYawNet 128、CPU速度優先ならYawNet 64を選べます。
  4. 4実際に使用する回転角ONNXを表示します。
  5. 5標準モデルの取得、または選択中の頭部モデルの公式ページを開きます。

各ドロップダウンの下に速度、特性、推奨環境、説明、ファイルの取得状況が表示されます。「自動」はPC上で見つかったモデルから推奨順に選びます。特定モデルを明示した場合、ファイルがなければ別モデルへ勝手に置き換えません。

実行デバイスは通常「自動（GPU優先・推奨）」を使用します。DirectML版はDirectX 12対応GPUを利用でき、使えない場合はCPUへ戻ります。詳しい分類と選択規則はMODEL_SELECTION.mdにまとめています。

標準モデルの重みはVirtual Headとは別の第三者著作物です。「ライセンス・情報」から各公式配布元と条件を開き、予定する利用・商用利用・再配布が許可されるかをご自身で判断してください。ダウンロード機能は権利や許諾を保証しません。

Gold-YOLO-N Headを使う場合は一覧から「おすすめ：Gold-YOLO-N 192×320」を選び、公式配布元から取得したgold_yolo_n_head_0277_0.5071_1x3x192x320.onnxを指定します。このモデルは標準ダウンロードには含まれません。

詳細設定

  1. 1CUDA版でDLLが自動検出されない場合だけフォルダを指定します。DirectML版では不要です。
  2. 2顔の傾きの補助推定が必要な場合だけランドマークを有効にします。
  3. 3有効化した場合のランドマークONNXを指定します。
  4. 4音声付きH.264保存を行う場合はFFmpegを指定します。

頭の見た目を調整する

  1. 1頭の拡大率。初期値18%は検出した頭の基準サイズの1.18倍です。
  2. 2固定Pitch。頭の上面・下面の見え方を調整します。
  3. 3左右の位置ずれを補正します。
  4. 4上下の位置ずれを補正します。負の値で上へ移動します。
  5. 5追従の揺れを平滑化します。
  6. 6Skinの髪・帽子レイヤーを表示します。

開始・停止・保存

  1. 1処理を開始します。
  2. 2動画やカメラ処理を安全に終了します。
  3. 3この説明書を開きます。
  4. 4「最新版・Release」でGitHubの配布ページを開きます。
  5. 5ライセンス・情報、設定保存、直近の保存先を開きます。

うまく動かないとき

開始できない

入力、頭部検出モデル、回転角モデルの選択を確認します。

GPUにならない

処理中の実行デバイス表示を確認します。DirectML版はDirectX 12対応GPUを使い、利用できなければCPUへ戻ります。

頭がずれる

拡大率、左右・上下位置、固定Pitchを少しずつ調整します。

診断ログは%LOCALAPPDATA%\VirtualHead\app.log、実行結果は出力先のrun.jsonにあります。

映像、画像、SkinはPC内で処理され、外部へ送信されません。標準モデルの取得を選んだ場合だけGitHubへHTTPS接続します。これは非公式アプリであり、MojangまたはMicrosoftの承認・提携を受けていません。
